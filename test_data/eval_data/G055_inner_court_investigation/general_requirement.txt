## 使用规范 [G01–G04]

- 将下述设定视为统一的设计约束；若平台能力有限，优先保留主线、潜行、线索板、警戒与多结局。
- 生成可游玩的第三人称单机冒险，主线时长约 12–16 小时，支线 5–8 小时。
- 目标平台：PC；全程仅使用键盘与鼠标；支持自动存档与手动存档。
- 画面：写实风格化架空古代宫廷美术，避免历史纪录片式写实；夜景需保证可读性。
- 默认难度“宫规”，提供“初入宫门”“宫规”“深宫夜行”三档。
- 所有数字均为初始平衡值，可在内部测试后整体微调 10%–20%，不得改变核心关系。
- 不允许把“解谜”退化成单一密码锁；同一目标至少提供两种解法或两条路径。
- 不允许把女性角色写成单一善恶标签；每位关键人物都要有利益、恐惧、底线与可验证动机。
- 战斗是高风险备选，不是主要解题方式；击杀关键人物不能成为默认最优解。
- 生成对话时避免挪用任何既有影视台词，采用原创表达与新情境。

## 1. 一句话概念与体验承诺

玩家扮演沈知微，在一座以礼法、流言、门禁和人情构成的“活迷宫”中调查一份被篡改的宫廷名册；通过观察、伪装、潜行、机关、证词交叉验证与关系经营，在保全自己及同伴的前提下决定真相如何被揭开。

### 1.1 体验支柱

- 读懂空间：宫殿不是走廊集合，而是由视线、作息、门禁、值守和礼仪共同组成的可推理地图。
- 先观察再行动：听脚步、看巡逻、辨衣饰等级、记录谁能进入哪扇门。
- 以身份作工具：借衣、借差事、借人情，不同身份开启不同通路，也带来不同风险。
- 让线索彼此说话：物证、证词、时间表、账簿和关系网互相验证。
- 选择有回声：短期安全、长期信任、名声、证据完整度影响后续章节与结局。
- 失败仍推进：被发现后可能引发盘问、搜查、禁足或关系损失，不用频繁读档重来。

### 1.2 目标受众与内容边界

- 适合喜爱叙事冒险、潜行、推理与角色关系经营的玩家。
- 建议年龄分级：青少年以上；不描写酷刑细节、血腥处决或性暴力。
- 宫斗冲突以权力、名誉、资源、信任和制度压力呈现。
- 玩家可选择克制、合作、欺瞒或揭发；不强迫玩家采用单一“正确”道德路线。

## 2. 世界背景与故事前提

架空大周王朝，年号景和。宫中准备修订《内廷岁档》，它记录各宫人员调动、赏赐、药材领用、出入时辰与旧案批注。档案中一页“冬至夜值房名册”被人调包，牵涉多年前的一场火灾与一位被迫离宫的女官。
沈知微以新人身份入宫，最初只想安稳度日。她在锦瑟院发现一只不属于自己的旧香囊，内藏半张值房轮值签。顾怀青提醒她：香囊上的药香配方不可能来自御药房常规领用。许令仪则发现某名册页码与当值太监的口供对不上。玩家由此开始查案。
案件并非简单的“找出坏人”：名册被改动可能是为掩盖救人、栽赃、替人顶罪或换取权力。玩家需确认谁改、为何改、谁受益、何时能安全公开。

### 2.1 章节结构

- **序章：初入宫门**：熟悉操作、礼法、第一条巡逻路线；完成一次不伤人的潜入。 目标：找回遗失的引荐牌，并确认锦瑟院并非随机分配。
- **第一章：锦瑟院夜香**：调查香囊、药材与夜间值房；建立线索板。 目标：证明香囊来自宫中旧库，而非玩家角色自带。
- **第二章：花影与名册**：潜入尚仪局、花房与档房，拼出轮值表。 目标：确认名册被改的时间窗口及三名可接触档案的人。
- **第三章：宫宴无声**：大型社交潜行关；礼仪、视线、座次与菜品成为谜题。 目标：在不引发公开冲突下取得宴前药膳记录。
- **第四章：雨夜太医院**：纵向探索太医院屋脊、回廊、药库；追查药材批次。 目标：将两份证词与实物批号对应，决定是否保护证人。
- **第五章：冷宫旧档**：限时搜证与情感抉择；老宫人提供互相矛盾的记忆。 目标：找到火灾当夜的原始抄录，确认被隐去的救援路线。
- **第六章：御前校档**：终局潜入；通过多条路线进入校档房，安排证据呈递顺序。 目标：玩家决定证据、对象、时机与承担后果的人。
- **尾声：墙外春信**：依据前述变量呈现不同结局与人物关系收束。 目标：展示选择的长期影响，不以单一分数评价玩家。

## 3. 核心循环

1. 抵达区域：查看区域平面、门禁和当日作息摘要。
2. 观察环境：标记守卫、闲谈、可攀爬点、遮蔽物、器具与异常物。
3. 提出假设：在笔记本写下“谁、何时、凭什么、可能路线”。
4. 选定身份与路线：制服、差事、口令、关系或环境机关。
5. 执行行动：潜行、交谈、取证、解锁、调度 NPC 或制造转移注意。
6. 处理后果：警戒、怀疑、信任、证据完整度与宫中流言变化。
7. 回到安全点：整理证据，解锁新的推理问题和下一章入口。

### 4.2 难度系数

| 难度 | 侦测倍率 | 线索提示 | 盘问宽限 | 解谜辅助 |
|---|---:|---|---:|---|
| 初入宫门 | 0.70 | 关键线索自动标注一次 | 2 次失误 | 开启机关轮廓与路线提示 |
| 宫规 | 1.00 | 需主动观察 | 1 次失误 | 可选轻提示，不给答案 |
| 深宫夜行 | 1.25 | 不自动标注 | 0 次失误 | 无方向提示，仍保留无障碍选项 |

- 难度只影响侦测速度、提示和容错，不改变剧情可达性。
- 重要证据不得因随机骰点彻底丢失；失败应改变取得成本或证据质量。
- 存档点设在安全屋、章节转换点和重要社交场景前。

### 4.3 判定公式

潜行成功率 = 基础值 55 + (潜行熟练 - 50) × 0.55 + 环境修正 + 身份匹配修正 - 警戒惩罚。
交涉成功率 = 50 + (礼仪或洞察 - 5) × 6 + 信任修正 + 证据支撑 - 对方戒心。
解锁成功不采用纯随机：工具、观察到的结构线索与操作节奏决定结果；失误增加噪声或耗时。
任何概率判定需显示“稳妥 / 有风险 / 高风险”三档提示，不强制显示精确百分数。
环境遮蔽修正：屏风 +20，暗处 +15，拥挤人群 +10，空旷明处 -20，逆光窗前 -10。
身份匹配修正：同差事 +20，临时借衣 +10，衣饰等级不符 -15，口令过期 -25。
证据支撑修正：一项独立物证 +10，两项相互独立证据 +20，单一传闻 +0。

### 5.1 能力成长

- 技能点每章 1 点，支线与无伤关卡可额外获得，总上限 12 点。
- 体力、敏捷、洞察、礼仪、记忆、交涉、潜行均可升级；单项上限 10。
- 专精不要求玩家全能；低属性通过道具、同伴帮助和替代路线补足。
- 沈知微不具备超自然能力；“感知”表现为专注观察与推断，不是透视。

### 5.2 玩家弱点与约束

- 新人身份：资历不足，主动命令太监或宫女会增加怀疑。
- 行动窗口短：宵禁后长时间停留会逐步抬高区域警戒。
- 非战斗专家：正面对抗最多制服普通看守，无法击败精锐护卫。
- 关系有代价：替某人隐瞒一次可能让另一条线索延迟出现。
- 证据需保全：湿纸、易挥发香灰、被污染器具会降低证据强度。
- 礼法能保护也能限制：公开质疑高位人物会迅速改变名声。

## 6. 潜行与身份扮演 [P02]

潜行的核心不是蹲伏，而是“看起来有理由出现在这里”。每个区域都标注可进入身份、合理行动、禁区与盘问触发点。

### 6.1 身份类型

| 身份 | 可进入区域 | 优势 | 风险 |
|---|---|---|---|
| 嫔妃随侍 | 外廷偏厅、寝殿外间 | 可随队通行、解释简单 | 被问主位姓名或差事时需答对。 |
| 尚仪局女史 | 礼仪房、典册架外围 | 可查看排班与仪式用具 | 衣饰细节严格，错用称谓易露馅。 |
| 医女 | 太医院药房、诊候廊 | 可接触药材与病历摘要 | 需辨认药名，错误配伍会暴露。 |
| 花房杂役 | 花房、内苑小径 | 可携带花木与剪具 | 不适合进入档案重地。 |
| 传膳宫人 | 膳房、宴席后廊 | 可在宴前后穿行 | 托盘被检查时需有真实单据。 |
| 内侍书办 | 档房外间、值房 | 可询问纸张与印泥 | 身形、口音或腰牌不符会遭盘问。 |
| 无身份便装 | 公共区域、暗道 | 低期待值、无制服限制 | 所有正式门禁都需绕行。 |

### 6.2 伪装规则

- 服饰分主色、纹样、腰牌、鞋履、配饰五项；至少四项匹配才算稳定伪装。
- 衣物可借、换、污损或被认出；重要角色记住玩家常用装束。
- 同一身份连续使用超过 3 个区域，会触发“熟面孔”检查。
- 伪装不等于隐身：同僚会提出符合身份的问题，回答可由线索或记忆准备。
- 禁止在高位人物面前使用低阶身份；尊卑差错增加怀疑 25 点。
- 每套伪装有“合理停留时间”，通常为 4–8 分钟，真实差事可延长。

### 6.3 侦测模型

- NPC 侦测由视线、距离、光照、噪声、身份、行为异常六项共同决定。
- 视线锥分近视 0–5 m、中视 5–12 m、远视 12–20 m；屏风和门框会遮挡。
- 脚步噪声：慢走 5、快走 15、奔跑 35、碰撞物件 45（0–100）。
- 对话噪声：轻声 5、普通交谈 12、争执 35、呼喊 60。
- 发现异常先进入“留意”2 秒，再进入“确认”5 秒，最后进入“追查”。
- NPC 可看到玩家进入掩体；掩体不能抹除已有目击。
- 警戒低于 25：闲谈；25–49：巡逻改变；50–74：临时盘查；75–99：搜查封门；100：抓获或章节级后果。

## 7. 证据推理与线索板 [P03]

线索板是玩家的工作台，不是自动给出答案的剧情百科。每条线索记录来源、时间、可信度、可验证点和潜在偏见。

### 7.1 证据类别

- 实物证据：纸张纤维、封泥、香灰、药包、衣料纤维、锁具磨损。
- 记录证据：轮值册、赏赐账、药材领用单、宴席座次图、门房簿。
- 口述证据：证人回忆、闲谈、盘问口供；需考虑恐惧、利益与记忆偏差。
- 空间证据：脚印方向、可达路线、视线死角、门窗开合痕迹。
- 关系证据：谁替谁传话、谁有权限、谁在关键时辰缺席。

### 7.2 线索质量

| 质量 | 分值 | 表现 |
|---|---:|---|
| 流言 | 10–24 | 来源模糊，只用于提出假设。 |
| 线索 | 25–49 | 存在事实指向，但可能有替代解释。 |
| 佐证 | 50–74 | 有独立来源或可复验细节。 |
| 强证据 | 75–89 | 能排除多数替代解释，来源完整。 |
| 决定性证据 | 90–100 | 能重建事件链，且保全与来源链可靠。 |

#### 7.2.1 证据强度的计算口径

证据强度不是主观印象值。每条证据建立时先计算基础分，再按验证、独立性、来源链和保全状态加减分；系统将结果限制在 0–100。
`证据强度 = clamp(基础可靠度 + 可复验分 + 独立佐证分 + 来源链分 + 保全分 − 污染/胁迫/矛盾扣分, 0, 100)`

| 组成项 | 范围 | 计算口径 |
|---|---:|---|
| 基础可靠度 | 0–40 | 证据类型与原始完整程度；原件高于转述件，直接观察高于传闻。 |
| 可复验分 | 0–20 | 其他角色或玩家能否重复检查同一特征；验证步骤必须记录。 |
| 独立佐证分 | 0–20 | 不同来源、不同形成过程且结论相符的佐证；同源材料不重复计分。 |
| 来源链分 | 0–10 | 发现地点、时间、经手人和移交记录完整程度。 |
| 保全分 | 0–10 | 证据从取得至提交未受潮、混合、改写、拆封或遗失。 |
| 污染/胁迫/矛盾扣分 | 0 至 −40 | 污染 −5 至 −20；胁迫口供 −15 至 −30；无法解释的关键矛盾 −10 至 −25。 |

- 每条证据初次发现时，系统按类型赋基础可靠度：流言 10、未经核实口述 18、二手抄本 22、现场痕迹 25、原始账册或实物 30、可验证的原始记录 35、带完整封存信息的原件最高 40。
- 每完成一种有效复验，按难度加 5–10 分；同一验证动作不得重复加分。可复验分最多 20 分。
- 独立佐证按来源簇计算：同一证人重复讲述、同一账本的抄本、同一经手人转述都属于一个来源簇；每个新的独立来源簇最多加 10 分，独立佐证分最多 20 分。
- 来源链每记录一项加分：发现地点与时刻 +4、发现者 +2、移交记录 +2、封存状态 +2；总计最多 10 分。
- 完整封存 +10；有轻微但可解释的暴露 +5；受潮、混入其他样本或无人记录经手过程不得获得保全分，并按损害程度扣分。
- 胁迫获得的口供不能单独超过 49 分；须有至少一项独立物证或记录佐证，才可突破此上限。
- 证据强度描述“证据可信度与可用于推理的程度”，不直接等同于某人的罪责概率。高分证据仍可支持多个解释。
- 系统不允许靠反复点击、重复询问、重复提交同一物证刷分；每个证据 ID 的每个加分来源只结算一次。

#### 7.2.2 证据处理结果与分值变化

| 玩家操作 | 分值变化 | 适用条件 |
|---|---:|---|
| 找到原件而非转抄件 | +8 至 +15 | 原件与副本能明确区分，且原件未被篡改。 |
| 完成笔迹、页码、印泥或纤维对照 | +5 至 +10 | 对照对象有可靠来源，方法在游戏内有说明。 |
| 由独立角色复验实物 | +5 至 +10 | 复验者未参与证据形成或此前的转述。 |
| 找到第二种独立记录相互印证 | +10 | 两份记录非同源抄写，且关键时间或对象一致。 |
| 补齐发现与移交记录 | +2 至 +8 | 仅补记真实发生且可验证的经手过程。 |
| 私自拆封、涂改、混样 | −10 至 −25 | 损伤程度由操作和后续可复验性决定。 |
| 证人口供明显受胁迫 | −15 至 −30 | 口供仍可作线索，但可信度下降。 |
| 出现无法解释的关键矛盾 | −10 至 −25 | 矛盾须涉及时间、地点、身份或物品来源。 |

#### 7.2.3 算分示例：旧香囊残灰

- 初始发现：现场实物，基础可靠度 30；尚未验证、来源记录不全，初始强度 30。
- 记录锦瑟院发现地点、当时时刻与发现者：来源链 +6，变为 36。
- 虞蘅独立比对香样，确认灰烬特征：可复验 +8，变为 44。
- 找到花房领用单，记录显示同批香料进入旧库：独立佐证 +10，变为 54。
- 再由顾怀青检查灰烬中混入的药材纤维：可复验 +7，变为 61。
- 将残灰封入独立纸包并登记交接：保全 +10，变为 71（佐证级）。
- 若另找到未经转抄的旧库原始账册并确认批号，再加独立佐证 +10，变为 81（强证据）。
- 若玩家把残灰与另一香样混在一起，先扣 15；后续仍可靠独立账册和未污染残留恢复部分证明力，但不能恢复已失去的样本信息。

#### 7.2.4 生成提示词必须输出的字段

每个证据对象都必须输出：`证据ID、名称、类型、发现位置、发现时间、发现者、基础可靠度、当前强度、来源簇、可复验点、独立佐证、来源链状态、保全状态、污染风险、支持的假设、可能的替代解释、强度变化日志`。
每次强度变化都必须给出具体原因，例如“+8：完成纸张纤维对照”，不能只显示“证据更可靠”。
玩家调查界面显示强度等级与变化理由；开发者调试界面显示每项分值。不得向玩家隐藏扣分原因。

### 7.3 推理操作

- 连接两条线索：建立“支持 / 矛盾 / 依赖 / 同源”关系。
- 建立时间线：把时辰、巡更、差事、天气与门禁放到同一刻度。
- 提出人物假设：标明动机、机会、权限和反证。
- 重演路线：在俯视图上验证某人在限定时间内能否到达某地。
- 校验来源：对比笔迹、印泥、页码、纸张批次和经手人。
- 提交推论：选择公开、私下询问、继续调查或暂缓。

### 7.4 推理失败处理

- 错误指认不锁死主线，但会损害关系或令目标转移。
- 证据不足时，系统给出“还缺权限 / 时间 / 独立来源”提示，不透露答案。
- 玩家可撤回假设；已公开的指控不可完全收回，会形成长期名声变量。
- 自动辅助模式会把关键推理分成三问，玩家仍需选择证据。

## 8. 礼法、关系与资源 [P04]

### 8.1 关系维度

每位重要角色包含：信任、好感、戒心、亏欠、秘密知情度五项。信任影响合作，好感影响私人交流，戒心影响盘问，亏欠影响请求，秘密知情度影响结局。
一次选择可同时提高一项、降低另一项；不得把关系压成单一好感条。

### 8.2 宫中名声标签

- 稳重：公开行动更易被解释为谨慎，秘密调查耗时略增。
- 聪慧：NPC 更愿意谈论事务，敌对者更早注意玩家。
- 温厚：求助门槛降低，强硬盘问难度上升。
- 锋芒：资源调度更快，高位人物戒心增加。
- 守礼：正式场合宽容度增加，临场伪装弹性降低。
- 多疑：线索提取更快，闲谈关系获取变慢。

### 8.4 物资获取规则

- 普通物资允许探索补足；关键剧情道具不设随机掉落。
- 每章提供至少三种非付费获取途径：探索、关系请求、以物易物。
- 打点不会购买关键人物的沉默，只影响杂务流程或短暂延迟盘问。
- 物资救援：若同伴因玩家选择失去住所或差事，可花 1 人情 + 3 两安排临时落脚。
- 资源不足时仍可继续主线，系统转为耗时、风险或关系代价。
- 商贩每日限量 2–4 件，价格受名声与宫中流言影响，浮动不超过 30%。

## 10. 压力来源与应对方式 [P06]

本作没有怪兽或外星阵营；对抗对象是由制度、信息、门禁与具体执行者组成的宫廷权力网络。战斗力数值表示对玩家造成的追捕压力，不代表善恶。

### 10.1 势力层级

| 层级 | 单位 / 角色 | 压力值 | 主要能力 | 破解方式 |
|---|---|---:|---|---|
| 顶层 | 皇帝与内廷裁决流程 | 100 | 改变规矩、封锁区域、决定证据是否进入审阅。 | 决定呈递对象与时机，拿出可复验链条。 |
| 高层 | 乔婉宁与闻素绮的代理网络 | 85 | 调度宫人、制造名声压力、提高区域检查。 | 拆分信息来源、转移注意、利用利益差异。 |
| 中高层 | 内务府、尚仪局、太医院主管 | 65 | 控制账册、药材、排班和通行凭据。 | 流程核验、关系交换、找出记录矛盾。 |
| 执行层 | 掌事宫女、值房内侍、巡查太监 | 45 | 盘问身份、封门、追踪脚印与物件。 | 合规差事、伪装、绕路、提交真实单据。 |
| 基层 | 门房、杂役、膳房帮工 | 25 | 提供目击、传话或短时阻拦。 | 礼貌交涉、帮助其完成差事、避免惊动。 |
| 环境 | 宵禁、雨雪、宴席、礼仪流程 | 10–60 | 改变可见度、通行、噪声与时间窗口。 | 观察规律、改路线、借环境掩护。 |

### 10.2 应对原则

顶层决定规则，中层掌握记录，基层掌握现场。玩家不能靠击败基层解决高层问题；必须逐层取得可验证信息并找到制度上的合法入口。
- 顶层角色不会成为可战斗 Boss。
- 高层威胁通过时间表、门禁和代理命令呈现。
- 中层弱点是手续和交叉记录。
- 基层弱点是重复工作、有限视野与真实的人情需求。
- 环境压力随章节动态变化，不做无提示的随机惩罚。

## 11. 轻度动作与非致命冲突 [P07]

- 玩家可推门、翻越矮墙、攀爬柱廊、滑入桌下、熄灯、转移器物。
- 近身动作仅有挣脱、短暂制服、遮挡视线三类；制服普通看守需 2.5 秒贴近操作。
- 精锐护卫无法被正面制服；玩家应逃跑、藏匿、求援或谈判。
- 武器只出现为环境道具，不提供大规模杀伤能力。
- 冲突后果：受伤降低耐力，制服看守增加 20 警戒并可能损害同伴信任。
- 无伤通过可解锁“无声行者”叙事称号，不给予过强数值优势。

## 12. 谜题与机关 [P08]

### 12.1 谜题设计原则

- 每个主要谜题至少有观察、推理、互动三个步骤。
- 谜题线索需在同一区域或前一安全区域可取得；不依赖像素级搜寻。
- 同一目标至少两个解法：身份路线、环境路线、关系路线、证据路线任选其二。
- 谜题答案应可从世界规律推出，不能靠无提示猜数字。
- 失败反馈必须说明错在时间、工具、顺序或前提，不直接给答案。
- 机关不会要求玩家反复做无意义的精确操作。

### 12.2 可复用机关组件

1. **屏风视线棋盘**：移动屏风改变守卫视线，同时制造可观察的影子缺口。
2. **漏刻计时机关**：读取水位、滴漏速度和巡更节奏，推算安全窗口。
3. **纸页拼接**：根据页码、纤维、裁边与墨色恢复被换页顺序。
4. **香气辨识**：比较燃烧残香、香囊残留与药材气味；需注意通风方向。
5. **回廊声学**：拍击、脚步与滴水声帮助判断空房、夹墙和门后距离。
6. **花木位置**：利用花盆移动痕迹、浇水记录和季节差异还原人员路线。
7. **礼仪顺序**：座次、敬茶顺序、称谓等级构成社交逻辑谜题。
8. **腰牌校验**：比对铸纹、绳结、磨损和当日发牌登记，识别伪造通行证。
9. **衣饰替换**：在时间限制内匹配主色、腰牌、鞋履和差事物件。
10. **账簿对账**：将月例、药材、膳食与值房开支对照，找出不可能的记录。
11. **锁具结构**：观察锁舌磨损与钥匙齿痕，决定正确开锁工具与方向。
12. **窗棂投影**：根据月光角度推断某人是否能从庭院看见室内动作。
13. **烛火风向**：利用火焰偏移和烟迹判断暗门缝隙、通风道或刚有人经过。
14. **棋局复盘**：把一盘未完棋局对应到人物策略或时间顺序，不考复杂棋力。
15. **诗笺藏字**：依据纸张折痕和行距发现缺失字句，不使用外部典故知识门槛。
16. **药包配伍**：核对份量、包纸、封口与领料单，判断药材是否同一批次。
17. **宴席传菜**：按温度和出菜次序复原谁能在何时接触某道菜。
18. **园林路线**：以桥、假山、花窗与巡逻路线组成俯视路线推演。

## 13. 关卡总览 [P09]

各章沿用同一结构：目标、关键谜题、至少两条路线、证据状态与失败补救。每章只保留会改变玩法的独特细节。

### 序章：宫门与锦瑟院

- 区域规模：小型教学场；目标时长：约 12 分钟。
- 人员配置：1 名门房 + 2 名巡逻宫人。
- 谜题：引荐牌、门禁问答、屏风潜行。
- 证据目标：证明玩家已被安排进入锦瑟院。
- 风险与替代：警戒上限 35；被盘问可用引荐牌或拜托孟兰汀。

### 第一章：夜香留痕

- 区域规模：中型寝殿群；目标时长：约 35 分钟。
- 人员配置：3 巡逻 + 1 值夜女官。
- 谜题：香灰比对、窗棂视线、漏刻窗口。
- 证据目标：找到旧库香料批次与被剪断的线头。
- 风险与替代：警戒上限 55；误入寝殿触发盘问，不丢失证据。

### 第二章：尚仪局的页码

- 区域规模：中型办公区；目标时长：约 45 分钟。
- 人员配置：4 巡逻 + 2 书办。
- 谜题：纸页拼接、腰牌校验、值房时间线。
- 证据目标：取得轮值表抄本并识别三名接触者。
- 风险与替代：可借女史身份、夜间翻窗或请求许令仪正式查阅。

### 第三章：宫宴无声

- 区域规模：大型社交区；目标时长：约 50 分钟。
- 人员配置：8 关键 NPC + 6 服务人员。
- 谜题：座次谜题、传膳路线、对话伪装。
- 证据目标：确认宴前药膳记录来源。
- 风险与替代：警戒达到 70 会提前结束宴席但仍有后续补查路线。

### 第四章：雨夜太医院

- 区域规模：垂直探索区；目标时长：约 55 分钟。
- 人员配置：5 巡逻 + 1 护卫。
- 谜题：雨声掩护、药包配伍、屋脊路线。
- 证据目标：取得药材批号与独立证词。
- 风险与替代：湿纸需及时烘干；暴雨减少视线、增加滑落风险。

### 第五章：冷宫旧档

- 区域规模：限时探索区；目标时长：约 60 分钟。
- 人员配置：3 巡查 + 2 证人。
- 谜题：路线重演、火灾旧图、记忆校验。
- 证据目标：恢复原始抄录并安置姚素秋。
- 风险与替代：证人受惊会中断谈话，需先安排安全出口。

### 第六章：御前校档

- 区域规模：多路线终章；目标时长：约 70 分钟。
- 人员配置：高层盘问、巡查网络。
- 谜题：证据排序、呈递策略、双重门禁。
- 证据目标：决定公开范围与承担后果者。
- 风险与替代：警戒并非失败条件；高警戒提高呈递成本与风险。

### 尾声：春信

- 区域规模：叙事收束区；目标时长：约 20 分钟。
- 人员配置：无敌对单位。
- 谜题：信件选择、关系结算。
- 证据目标：展示结局及后续生活。
- 风险与替代：允许玩家查看变量摘要与未解问题。

### 13.1 代表性任务与谜题解法

每项任务至少包含观察、推理、行动三个环节。表中任一方案均可推进；失败改变代价，不锁死主线。

| 任务 | 关键线索 | 可行解法 | 失败后的继续方式 |
|---|---|---|---|
| 漏刻不说谎 | 漏刻水位、巡更锣声、未干水痕 | 计时进入；用屏风遮挡；请同伴引开守卫 | 警戒 +10，等待下一轮窗口。 |
| 一页三纸 | 纸纤维、裁边、墨色、装订孔 | 公开查册；找废纸边角；拓印目录对照 | 错拼只形成低可信假设，可重新核对。 |
| 同一枚腰牌 | 铸纹、绳结磨损、登记笔迹 | 正式核验；借差事接近登记册；询问制牌工匠 | 私取被发现会增加怀疑，但证据仍可补查。 |
| 无声的宴席 | 出菜次序、座位图、托盘余温 | 传膳伪装；客人请求；宴后查厨房票据 | 宴席结束后改走厨房补查路线。 |
| 两种香灰 | 灰烬颗粒、香料账单、风向 | 虞蘅比香；玩家做小样；通风处复验 | 误判可由领料单和另一份样本纠正。 |
| 温药三问 | 药包封口、领料簿、煎煮时间、药渣 | 顾怀青协助；医女身份；私下取得配伍表 | 缺表时用药渣复验，耗时增加。 |
| 冷宫里的年份 | 旧历、节令、药方背面、修补痕迹 | 安抚证人；用实物提示；玩家建立时间线提问 | 证人中断谈话，可先安排安全出口再返回。 |
| 最后一盏灯 | 巡更节奏、灯油量、风向、同伴位置 | 调度同伴；合法差事；利用雨声撤离 | 可改走正门呈递，增加关系与时间成本。 |

其他机关可复用：窗棂投影推断视线、花盆痕迹复原路线、火漆裂纹判断封档是否开启、礼单座次推断空位用途、回廊回声定位夹墙。每种机关必须给出可观察线索和至少一种替代解法。

## 14. 任务与解锁 [P10]

### 14.1 主线解锁

- 序章完成后解锁第一章，无属性门槛。
- 第二章需“香料来源”或“值夜时间”任一线索达到佐证级。
- 第三章需获得一份正式宴席差事，或通过关系建立随行身份。
- 第四章需取得药材批号假设；若未取得，顾怀青可提供补查任务。
- 第五章需两条独立证据指向旧案时间段。
- 第六章不要求满证据；证据越完整，呈递风险越低、结局信息越清晰。

### 14.2 支线解锁示例

- “花房的旧账”：虞蘅信任 ≥ 20 或找到重复香料领用单。
- “许令仪的茶席”：名声 ≥ -10 且完成一次无冲突交涉。
- “冷宫的冬衣”：人情 ≥ 1 或发现旧档房的修缮记录。
- “满仓的暗格”：完成一次环境机关，不需要任何人物关系门槛。
- “医女的夜班”：取得药材批号，或以 2 两雇请短期抄录。
- “失而复得的腰牌”：被盘问一次后开启，以补救制度漏洞。

### 14.3 战力 / 能力阶梯

| 阶段 | 玩家解锁 | 效果 | 对应威胁 |
|---|---|---|---|
| 初入宫门 | 慢走、观察、基础交谈 | 识别视线与差事提示 | 基层盘问 |
| 熟悉规矩 | 稳定伪装、标注巡逻 | 同身份停留时间 +2 分钟 | 执行层巡查 |
| 善察人心 | 证词偏见提示、关系请求 | 辨认回避与矛盾，不自动判真伪 | 中层流程审查 |
| 暗线织网 | 同伴支援、两点同步调度 | 一次任务可安排一名同伴行动 | 高层代理网络 |
| 御前校档 | 证据链呈递、公开范围选择 | 决定由谁先看、哪些可封存 | 顶层裁决流程 |

## 15. 选择与结局 [P11]

### 15.1 全局变量

- truth_score：事实链完整度 0–100。
- evidence_integrity：证据保全度 0–100。
- public_exposure：公开程度 0–100。
- ally_safety：同伴安全 0–100。
- court_suspicion：宫廷总体怀疑 0–100。
- compassion_debt：玩家对他人承担的承诺与亏欠 0–10。
- witness_consent：证人是否自愿参与 0–100。

### 15.2 结局组

- 封存的真相：truth ≥ 75、public_exposure < 40、ally_safety ≥ 60；案件被纠正但对外只留下模糊记录。
- 庭前明证：truth ≥ 85、evidence_integrity ≥ 75、public_exposure ≥ 60；真相进入正式审阅，代价是关系与名声震荡。
- 各自求生：truth 45–74 或 ally_safety < 50；玩家保全部分同伴，证据仅能改动局部制度。
- 以名换路：truth ≥ 60、court_suspicion ≥ 75；玩家主动承担流言，换取证人脱身与关键文件保全。
- 宫墙回声：truth < 45；案件未能定论，但玩家留下的线索让后来者仍可继续追查。
- 春信归人（隐藏变体）：满足关键人物信任、证人自愿与低伤害路线；尾声额外显示同伴未来去向。

### 15.3 结局公平性

- 结局由累积变量触发，不由最后一个二选一独占决定。
- 结局前显示风险提示：公开范围、可能受影响人物、证据缺口。
- 不设置“全员幸福”单一完美结局；正义、安全、名声和自由之间存在真实取舍。
- 隐藏结局强调过程条件，不要求收集所有物品或完成所有支线。

## 16. NPC 与对话规则 [P12]

- NPC 以日程状态机运行：工作、巡查、休息、社交、应急。
- 重要 NPC 记住三类事件：玩家公开行为、承诺是否兑现、是否牵连无辜者。
- 对话提供观察、询问、转移、求助、试探、结束六类意图。
- 玩家可先观察再对话；观察到的细节可解锁具体问题。
- 角色不会凭空知道玩家在别处做的事，除非有明确传话路径。
- 谣言传播延迟为 10–30 分钟游戏时间；秘密不会瞬间全宫知晓。
- 同一问题重复盘问会使对方戒心 +10，除非出现新证据或新情境。
- NPC 说谎时不使用统一红字提示；玩家需通过矛盾、动机和行为判断。

## 17. 美术、声音与 UI [P13]

### 17.1 美术方向

- 色彩：朱红、黛青、暖金、旧纸白；不同区域通过灯温区分。
- 构图：门框、窗格、屏风形成层叠遮挡，强调“看见与被看见”。
- 角色轮廓：身份由袖口、腰牌、发饰与鞋履辨识，不靠头顶阵营色。
- 交互提示：低饱和线框，不使用现代科幻扫描效果。
- 环境变化：雨雪、烛火、雾气要影响玩法但不遮挡关键交互。

### 17.2 声音设计

- 脚步按木廊、石地、地毯、湿地分别设计声纹。
- 巡更锣、滴漏、风铃、膳房铜器形成时间与方向线索。
- 音乐以弦乐、箫、打击乐低频为主；追查时加入节奏但避免持续压迫。
- 证据发现使用短促细节声，不用夸张“正确答案”音效。
- 听觉提示可视化，支持听障玩家；视觉线索也能完成同一谜题。

### 17.3 UI 页面

- 任务页：当前目标、已确认事实、待验证假设分栏。
- 线索板：人物、地点、时间、物证四种节点，可筛选关联。
- 地图：门禁等级、光照、巡逻方向、可用身份和撤离点。
- 伪装页：衣饰匹配度、差事解释、剩余合理停留时间。
- 关系页：信任、戒心、承诺与可请求协助，不展示隐藏剧情变量。
- 资源页：数量、来源、可替代取得方式。
- 无障碍页：字幕、字幕说话人、文本大小、颜色模式、谜题提示强度。

## 18. 键盘鼠标操作与无障碍 [P14]

- 键盘：WASD 移动，E 互动，Q 专注观察，C 蹲伏，Tab 打开线索板，M 打开地图，Shift 快走，Esc 暂停。
- 鼠标：移动观察视角，左键确认 / 使用物件，右键取消 / 退出观察，滚轮切换可交互目标。
- 所有按键可重映射；潜行支持按住或切换模式。
- 提供字幕背景、字号、对比度、色盲方案与高亮交互轮廓。
- 所有听觉线索均有可选视觉方向提示。
- 谜题提示三级：主题提醒、已知条件整理、逐步提示；默认仅主题提醒。
- 限时关卡允许延长 25% 或关闭倒数；不影响结局资格。

## 19. 失败恢复与反挫败 [P15]

- 连续两次潜行失败后，第三次行动会出现可见的替代路线提示。
- 任务关键 NPC 不会因普通警戒永久死亡或消失。
- 同一区域被封锁后，提供等待、求助、合法申请或绕行四类恢复办法。
- 玩家丢失伪装后可在储物间、屏风后或安全屋更换，不强迫重开关卡。
- 证据损坏降低强度但不清除玩家已学到的信息。
- 支线错过可通过后续书信或口述补全背景，避免收藏品式遗漏惩罚。
- 重要状态变化给出具体原因，如“腰牌被登记为失窃”，不只弹出抽象失败提示。

## 20. AI 产出顺序 [P16]

1. 先生成全局系统：属性、警戒、身份、资源、关系、证据与结局变量。
2. 生成章节地图草图：标注门、巡逻、遮蔽、入口、撤离点和安全屋。
3. 为每章生成任务流程图，含至少两条路径与失败后恢复方案。
4. 生成角色日程表和对话状态，不允许 NPC 全程站桩。
5. 生成每个谜题的线索投放表、答案逻辑、替代解法与错误反馈。
6. 生成原创对话，标注说话意图、前置变量、关系变化和信息可信度。
7. 生成主线与支线的变量影响清单。
8. 生成难度与无障碍参数。
9. 最后输出可玩原型优先级：序章 + 第一章核心循环 + 线索板 + 一次结局变量结算。

## 21. 原型范围 [P17]

- 预计游玩时长：25–35 分钟。
- 场景：宫门、锦瑟院前庭、寝殿外廊、花房一角。
- 可玩角色：沈知微；支援角色：孟兰汀、阿蘩。
- 机制：移动、观察、潜行、身份检查、对话、线索板、简单解锁、警戒恢复。
- 主谜题：香囊来源与值夜时间窗口。
- 备选路线：女史差事、夜间屏风潜行、请求孟兰汀带路。
- 最低内容：3 个 NPC 日程、2 套伪装、5 条线索、3 个结论节点、1 个资源兑换。
- 原型完成标准：新玩家能在不看攻略的情况下说明自己为什么选择某条路线。

## 22. 范围与正向能力清单（创作边界，v3 正向化）[P18]

- N01 本作的核心能力：观察、潜行、身份伪装、证据推理、线索板关联、关系经营与礼法交涉；冲突为高风险备选（§11），不构成刷怪或数值碾压玩法。
- N02 谜题难度来自信息推理与空间观察；同一谜题均提供可观察线索与替代解法（§12.1）。
- N03 通关条件仅依赖本作文内信息；不要求任何历史或既有影视作品知识。
- N04 NPC 遵守尊卑、日程与已发生事件的记忆一致性；关系呈现为多维灰度而非善恶二元。
- N05 失败恢复以补救与替代路线为主（§19）；关键线索不因失败永久删除，不强迫重玩长段流程；克制路线获得等价内容与奖励。
- N06 能力判定基于证据、身份、环境与关系状态；身高体重不参与潜行、魅力或战斗数值。

## 25. 规则优先级 [P21]

- 剧情锁定 > 关键证据保护 > NPC 日程 > 玩家临时动作。
- 同一 NPC 同时处于巡逻与对话时，结束对话后从最近合理节点继续日程。
- 玩家在安全屋整理证据不消耗区域巡逻时间，但消耗章节时间推进。
- 区域警戒 ≥75 时门禁升级；警戒下降需要离开视线并等待 60 秒或完成合法差事。
- 怀疑值属于个人记忆，区域警戒属于群体反应；二者不可互相自动清零。
- 借来的制服归还或遗失需记入关系与物资，不允许无限复制。
- 同伴支援不可穿越封锁区瞬间出现；需明确展示其路线与耗时。

## 26. 最终生成命令 [P22]

请基于本设计先输出一个可玩的垂直切片，并严格遵守以下顺序：
1. 展示核心操作与一段原创开场剧情。
2. 提供锦瑟院周边俯视地图及门禁、视线、巡逻、可藏身点。
3. 实现至少两种潜入路线与一次身份盘问。
4. 实现香囊来源谜题，呈现可观察线索、线索板推理和错误反馈。
5. 实现一位同伴的可选支援，但不替玩家自动完成推理。

## 生成任务明确性补充（2026-10-12）

> 本补充只约束游戏生成输入，不引用 rubric。所有生成器必须以本文件规则和下列 JSONL 任务为准；未列出的装饰细节可以自由发挥，但不得省略已列资产或生命周期。

### 故事与流程最低合同
- **玩家身份与当前冲突**：以 §1、§8 的角色/世界/冲突为唯一叙事入口；开局必须让玩家知道“我是谁、现在要解决什么问题”。
- **阶段性目标**：必须有可操作的阶段目标、至少一次状态变化/升级，并在 §7 的胜利、失败、重开入口中闭环；不能只生成一个无结果的场景演示。
- **结果承接**：胜利/失败都要有明确结果文案或演出，并回到可重开、暂停或标题入口；视频、音频和 VFX 不得推进未完成的玩法状态。

### 生成任务清单（JSONL 冻结口径）
- scene：1 个；必须生成连贯可游玩的空间，不得出现下半部文字、拼贴面板、物体 lineup 或 UI。
- object：4 个（text-to-3D 2，image-to-3D 2）；object 任务资产为：shen_zhiwei, evidence_pouch_ash, rota_manuscript, seal_wax_imprint。每项只允许一个物体；组合物必须拆成独立任务。
- motion：4 个；覆盖动作：idle, walk, crouch_sneak, evidence_examine。
- video/audio/mechanic/UI：分别为 5/10/1/1 个任务；若某项为 0，只能是本案例明确的 N/A，不得默默遗漏。

### Video / motion / audio 生命周期
- Video 每项必须写清 `trigger`、`start_condition`、`duration_sec`、`skippable`、`skip_behavior`、`end_condition` 和进入的下一个游戏状态；播放期间不得偷偷消耗计时或改变战斗/任务数值。
- Motion 每项必须写清 `source_asset`、`trigger`、`start_condition`、`duration_sec`、`loop`、`end_condition` 和 `cancel_behavior`；动作要与对应输入/机制事件绑定，不可只写“walk animation”。
- Audio 每项必须写清触发事件、时长、`loop`、`stop_condition`、优先级和 ducking；关键命中/提示音必须与事件帧同步，暂停/结算时按 §9 处理。

### Mechanic / UI / 游玩手感
- Mechanic JSON 与 §1–§7 配对：每个输入都要有 precondition、state_change、feedback、next_state；必须说明失败/禁用分支。
- UI JSON 与 §9/F10 配对：HUD、菜单、结算、暂停、错误/禁用态要有 state binding；关键状态不能只用颜色表达。
- 手感冻结：相机跟随/构图、FOV、碰撞/遮挡、镜头调整与镜头震动必须在 §9 说明；震动反馈必须写明触发、强度和持续时间，并提供关闭设置且不改变判定。

### VFX 时机合同
每个特效必须写清 `trigger event`、预备/前摇、active window、持续时间、结束条件、被打断/取消条件，以及和相机震动、音效、UI 的同步关系；命中特效、失败特效、胜利特效不能只写“有粒子”。
