## 1. 定位与完整流程 [S01–S05]

- S01 类型：开放沙地改路塔防（无固定路线）。
- S02 核心循环一句话：放塔塑路 → 敌人寻路 → 调整布局 → 重算路径 → 守住基地。
- S03 流程：开始 → 波前建造/拆除 → 敌波按当前可行路径行进 → 波间调整 → 守满 5 波 → 胜利结算。
- S04 最低完整流程：建造/拆除操作、寻路可视化、波次结算、胜负结算、重开必须全部存在且有真实入口。
- S05 失败恢复入口：基地生命归零 → 失败结算一键重开；Esc 暂停。

## 2. 完整核心循环与阶段 [S06–S13]

完整循环：主菜单 → 开始对局 → 建造期（波前建造/拆除）⇄ 敌波行进 → 波次结算（共 5 波，波间回到建造期）→ 胜利结算；任意玩法阶段可 Esc 暂停；基地生命归零即时进入失败结算。每阶段六要素如下（引用本 spec §3–§7 对应规则）：

- S06 主菜单
  - input：系统启动，玩家确认进入
  - precondition：程序启动完成
  - state_change：显示主菜单（开始/退出）
  - feedback：主菜单界面
  - next_actions：玩家点击「开始」→ S07
  - outcome：无状态副作用
- S07 开始对局
  - input：玩家点击「开始」
  - precondition：主菜单已显示
  - state_change：对局初始化：金币 120、基地生命 3、波号 1、沙丘初始位置按 seed 冻结
  - feedback：HUD 显示初始值与当前最短路径长度（见 §4 I06）
  - next_actions：进入 S08 建造期
  - outcome：进入首波建造期；无跨局状态（见 §7 V05）
- S08 建造期（每波前）
  - input：玩家建塔/沙障/拆除（按 §4 I01/I02 键位）；Space 提前开波；倒计时归零（系统）
  - precondition：波号已确定；上一波已结算（首波为对局初始化）
  - state_change：进入建造期，倒计时 20 秒（见 §3 G06）；放置/拆除即时生效并触发路径重算
  - feedback：HUD 显示倒计时、下一波敌数与单只 HP、当前最短路径长度与预览（见 §4 I06）
  - next_actions：Space 或倒计时归零 → S09；Esc → S11
  - outcome：布局保留至本局结束
- S09 敌波行进
  - input：系统波调度（fixed_seed=1027 出生序列，每 1.0 秒出生一只）；塔自动交战；玩家仍可建/拆（波中可建可拆，不暂停敌人）
  - precondition：建造期结束（Space 或倒计时归零）
  - state_change：敌人按当前最短路径行进；放置/拆除生效瞬间触发分段重路由（见 §3 G04）；漏怪（抵达基地）→ 基地生命 −1
  - feedback：命中反馈与路径/重路由特效（见 §9 F05/F06）
  - next_actions：波内敌人清空或全部抵达基地 → S10；基地生命归零 → S13；Esc → S11
  - outcome：击杀金币入账；漏怪扣基地生命
- S10 波次结算
  - input：系统结算
  - precondition：波内敌人清空或全部抵达基地
  - state_change：波奖励 +40（见 §3 G03）；波号 +1；第 3 波结束时触发沙丘位移（见 §3 G07）
  - feedback：金币数字跳动（见 §9 F05）
  - next_actions：波号 < 5 → 回 S08；波号 = 5 → S12
  - outcome：进度推进；状态保留
- S11 暂停
  - input：玩家按 Esc
  - precondition：处于 S08/S09 任意玩法阶段
  - state_change：冻结敌人、寻路、塔、波调度与全部计时（见 §3 G05）
  - feedback：暂停菜单（继续/重开/返回菜单）
  - next_actions：Esc 或「继续」→ 返回原阶段；「重开」→ S07；「返回菜单」→ S06
  - outcome：恢复后一切计时从冻结点继续，无副作用
- S12 胜利结算
  - input：系统结算
  - precondition：第 5 波结束且基地生命 > 0（见 §7 V01）
  - state_change：显示胜利结算（路径总长、漏怪数、剩余金币）
  - feedback：胜利全屏特效（见 §9 F05）
  - next_actions：Enter 重开 → S07；返回菜单 → S06
  - outcome：按 §7 V01/V03 判定并结算
- S13 失败结算
  - input：系统结算
  - precondition：基地生命归零（任意波中即时判负，见 §7 V02）
  - state_change：显示失败结算
  - feedback：失败反馈
  - next_actions：Enter 一键重开 → S07；返回菜单 → S06
  - outcome：按 §7 V02/V03 判定并结算（全量重置）

## 3. 数值口径与全局规则 [G01–G07]

- G01 统一刻度：金币/HP 为整数；沙地为 20×20 格，坐标 (x,y) 从西北角 (0,0) 起，x 向东、y 向南；塔射程按格计，射程判定按格中心欧氏距离 ≤ 射程；时间用游戏模拟秒（暂停冻结）。
- G02 塔表（本包冻结值）：箭塔（造价 50、攻 10、射程 3、间隔 1.0 秒）；沙障（造价 30、不攻击、仅阻挡塑路）。箭塔与沙障均占格阻挡。基地生命 3；初始金币 120。
- G03 敌波表（本包冻结值）：5 波沙行蚁——数量 6/8/10/12/14，单只 HP 40/60/80/100/120，移速 1 格/秒；同波敌人每 1.0 秒出生一只（出生点＝西缘中点）。击杀金币 10/只；每波通关 +40。
- G04 寻路与改路（本包冻结值）：
  - 敌人出生点＝西缘中点 (0,9)，基地＝东缘中点 (19,9)；敌人四邻接移动（每步 1 格），路径「格数」按移动步数计。
  - 敌人始终走「出生点→基地」的最短可行路径；等长路径按 BFS 邻居顺序 东→北→南→西 展开取第一条，该条同时作为预览路径与实际路径。
  - **堵死放置非法（红线）**——任何使基地不可达的放置被拒绝且不扣费；有敌人占据或正在进入的格放置非法并拒绝；波中可建可拆。
  - 放置/拆除生效瞬间触发重算：场上敌人从当前所在格（移动中则从下一格）按新的最短路径继续行进。
  - 拆除返还 60%（沙障 30→18、箭塔 50→30），返还不得高于造价（防刷经济断言：建-拆循环净收益恒 ≤0）。
  - 箭塔默认攻击最接近基地的射程内敌人；伤害即时结算（命中帧生效，弹道仅为表现层）。
  - 路径长度 oracle 数例：20×20 空地出生点到基地最短 19 步；在 (10,9) 放 1 沙障后最短 21 步。
- G05 暂停与随机：Esc 暂停冻结敌人、寻路、塔、波调度与全部计时；fixed_seed=1027 冻结沙丘初始位置与沙丘位移目标格、波内出生序列；伤害为确定公式。
- G06 建造期规则（本包冻结值）：每波前建造期 20 秒倒计时，可按 Space 提前开波；建造期 HUD 显示下一波敌数与单只 HP；倒计时归零自动开波。
- G07 移动沙丘（本包冻结值）：场上预先标出 3 格沙丘，初始可通行、不可建造，位置由 fixed_seed=1027 冻结；第 3 波结束时沙丘各移至 seed 冻结的相邻格——被覆盖格变为不可通行，原沙丘格恢复为普通可建造格；若被覆盖格有建筑，建筑被掩埋并按造价 60% 返还；位移后全图重算一次路径（沙丘目标格由 seed 保证基地仍可达）；自第 3 波建造期起在地图上高亮预告目标格。

## 4. 操作与输入 [I01–I06]

- I01 键鼠：点击空格＋塔型＝建塔；点击己方塔＋拆除钮＝拆除（返还 60%）；1/2＝快捷选塔型；Space＝建造期提前开波；Esc＝暂停；结算界面 Enter＝重开。
- I02 输入语义边界：金币不足无效；堵死路径的放置非法拒绝且不扣费（红线）；有敌人占据或正在进入的格放置非法拒绝；拆到 0 返还不为负；暂停/结算期间输入无效。
- I03 无手柄需求。
- I04 输入优先级：暂停与结算状态阻断全部玩法输入；面板打开时玩法键不串入（沿用原 I02 口径）；同帧多输入按 §6 各机制声明的顺序结算。
- I05 焦点与点击穿透规则：点击画布捕获输入焦点；面板层阻断点击穿透；窗口失焦自动暂停，不推进游戏模拟。
- I06 UI 必须显示的状态：金币、波次号、基地生命（按 §3 G01 刻度）；建造期倒计时与下一波敌数/单只 HP（见 §3 G06）；当前最短路径长度实时显示，且当前可行路径实时可视预览（冻结要求，供玩家塑路决策，预览＝实际路径）；沙丘位移预告高亮（见 §3 G07）；悬停建造格显示射程圈与合法性（绿/红，见 §9 F05）。
- I07 输入延迟目标：点击到画面反馈 ≤150 毫秒（WebGL 口径，P95，≥30 次采样/类别）。

## 6. 机制系统 [M01–M04]

- M01 放塔改路与必达断言（主机制）
  - input：建塔/沙障放置指令（按 §4 I01 键位）
  - precondition：金币 ≥ 造价；目标格为空地、无敌人占据或正在进入、非沙丘格；放置后基地仍可达（红线）
  - state_change：占位生效（箭塔/沙障均阻挡）→ 全局最短路径即时重算
  - output：按 §3 G02/G04 结算路径与攻击（公式见对应 G 条）
  - observable：放置事件、路径重算事件（新旧路径长度）、非法放置拒绝事件（堵死/有敌格/边界）
  - invalid_case：金币不足、堵死、有敌格、边界外放置按 §4 I02 拒绝且无副作用；暂停/结算期间玩法输入无效
  - recovery：失败/中断/非法态后的恢复按 §7 V03 恢复语义与 V04 软锁处理执行，不产生冻结规则之外的副作用
- M02 路径重算与分段重路由
  - input：放置/拆除/沙丘位移生效瞬间（系统）
  - precondition：场上存在行进中敌人
  - state_change：敌人从当前所在格（移动中则从下一格）按新的最短路径继续行进
  - output：按 §3 G04 结算（新路径长度、敌人后续轨迹）
  - observable：每敌重路由事件（旧/新路径段）、新路径高亮 0.5 秒（见 §9 F05）
  - invalid_case：重算后基地不可达的放置在 M01 已被拒绝，重路由不处理不可达局面
  - recovery：按 §7 V03/V04 执行
- M03 拆除退款
  - input：拆除指令（按 §4 I01 键位）
  - precondition：目标格有己方建筑（波前或波中均可拆）
  - state_change：建筑移除、返还造价 60%（沙障 30→18、箭塔 50→30）、路径重算
  - output：按 §3 G02/G04 结算退款与路径
  - observable：拆除事件与金币流水（建-拆循环净收益 ≤0 断言）
  - invalid_case：拆除返还不得为负；金币不足的建造拒绝不扣费（见 §4 I02）
  - recovery：按 §7 V03/V04 执行
- M04 沙丘位移
  - input：系统（第 3 波结束时）
  - precondition：第 3 波结束（波内敌人清空或全部抵达基地）
  - state_change：3 格沙丘各移至 seed 冻结的相邻格；被覆盖格变为不可通行，原格恢复可建造；被掩埋建筑按造价 60% 返还；全图重算一次路径
  - output：按 §3 G07 结算（掩埋返还、新路径）
  - observable：沙丘位移事件、掩埋返还流水、重算前后路径长度
  - invalid_case：位移目标格由 seed 冻结，不依赖玩家操作，无非法态；位移不发生在其他时机
  - recovery：按 §7 V03/V04 执行

## 7. 成功、失败与恢复 [V01–V05]

- V01 成功条件：第 5 波结束（波内所有敌人被击杀或已抵达基地）时基地生命 > 0 → 胜利结算（显示路径总长、漏怪数、剩余金币）。
- V02 失败条件：基地生命归零（累计漏 3 敌）→ 失败结算（任意波中即时判负）。
- V03 恢复语义：失败/胜利结算一键重开（Enter）；布局、金币、波次、基地生命、沙丘位置全量重置。
- V04 软锁与不可达处理：无永久软锁——关键目标均可通过正常操作达成，或触发 V02 失败路径进入结算；结算界面重开为最终恢复出路；判定不可达时按 V02 失败语义结算而非无限等待。
- V05 persistent_state 生命周期：当前动作级状态即时结算；当前局级状态（金币/布局/基地生命/波次）局内保留、重开清空；无跨局保留（重开全量清空）。

## 8. 世界设定与创作基线 [W01–W08]

- W01 世界与时代背景：流沙纪元，风蚀荒漠深处的绿洲「泉眼堡」依靠地下暗河维系；每逢旱季，掠食性沙蚁群循着水汽沿固定方向迁徙，所过之处寸草不留。
- W02 场景所在地：20×20 开放沙地；西缘蚁穴为敌人出生点，东缘前哨基地为防守目标；三座风驱沙脊（移动沙丘）横亘其中，随风力缓慢位移。
- W03 玩家身份与当前任务动机：玩家是泉眼堡的防线工程师「筑垒者」；旱季将至，蚁群循水汽而来——在蚁群与基地之间的开放沙地上用箭塔与沙障塑出一条迂回长路，耗死蚁群。
- W04 失败代价与结局表达：基地失守=泉眼堡水脉断流（C02 失败意象：沙蚁涌入基地）；守住 5 波=蚁群绕道而走（C02 胜利意象：基地旗帜舒展、蚁群远去）。
- W05 叙事来源：沙行蚁=荒漠掠食蚁（原创造型）；沙障=夯沙板墙；箭塔=木质弩架；移动沙丘=风驱沙脊；前哨基地=泉眼堡哨站。全部原创，不用商业作品命名。
- W06 视觉风格与色彩材质：荒漠军事风；主色＝沙金 #D8B96A、赭石 #A9744F、烈日白 #F5EFE0、警报赤 #C0392B；材质为风化岩、帆布、木制弩架。
- W07 环境氛围与声音语言：沙漠风啸为底；音效语言＝建造落位/拆除塌落/路径重算提示/蚁啸警报/命中木屑/波次横幅（F06 冻结清单）；混音优先级：基地警报 ＞ 波次横幅 ＞ 命中 ＞ 建造/拆除 ＞ 环境风。
- W08 故事表达方式：开场视频（C01）交代蚁群来袭与塑路任务 → 过程事件（F05 特效与沙丘位移预告）承载「荒漠在移动」的过程叙事 → 结算视频（C02）双意象收束；叙事提示不阻断控制、不改变数值。

## 生成任务明确性补充（2026-10-12）

> 本补充只约束游戏生成输入，不引用 rubric。所有生成器必须以本文件规则和下列 JSONL 任务为准；未列出的装饰细节可以自由发挥，但不得省略已列资产或生命周期。

### 故事与流程最低合同
- **玩家身份与当前冲突**：以 §1、§8 的角色/世界/冲突为唯一叙事入口；开局必须让玩家知道“我是谁、现在要解决什么问题”。
- **阶段性目标**：必须有可操作的阶段目标、至少一次状态变化/升级，并在 §7 的胜利、失败、重开入口中闭环；不能只生成一个无结果的场景演示。
- **结果承接**：胜利/失败都要有明确结果文案或演出，并回到可重开、暂停或标题入口；视频、音频和 VFX 不得推进未完成的玩法状态。

### 生成任务清单（JSONL 冻结口径）
- scene：1 个；必须生成连贯可游玩的空间，不得出现下半部文字、拼贴面板、物体 lineup 或 UI。
- object：6 个（text-to-3D 4，image-to-3D 2）；object 任务资产为：arrow_tower, sand_barrier, moving_dune, ant_burrow, sand_ant, outpost_base。每项只允许一个物体；组合物必须拆成独立任务。
- motion：1 个；覆盖动作：dune_shift。
- video/audio/mechanic/UI：分别为 2/13/1/1 个任务；若某项为 0，只能是本案例明确的 N/A，不得默默遗漏。

### Video / motion / audio 生命周期
- Video 每项必须写清 `trigger`、`start_condition`、`duration_sec`、`skippable`、`skip_behavior`、`end_condition` 和进入的下一个游戏状态；播放期间不得偷偷消耗计时或改变战斗/任务数值。
- Motion 每项必须写清 `source_asset`、`trigger`、`start_condition`、`duration_sec`、`loop`、`end_condition` 和 `cancel_behavior`；动作要与对应输入/机制事件绑定，不可只写“walk animation”。
- Audio 每项必须写清触发事件、时长、`loop`、`stop_condition`、优先级和 ducking；关键命中/提示音必须与事件帧同步，暂停/结算时按 §9 处理。

### Mechanic / UI / 游玩手感
- Mechanic JSON 与 §1–§7 配对：每个输入都要有 precondition、state_change、feedback、next_state；必须说明失败/禁用分支。
- UI JSON 与 §9/F10 配对：HUD、菜单、结算、暂停、错误/禁用态要有 state binding；关键状态不能只用颜色表达。
- 手感冻结：相机跟随/构图、FOV、碰撞/遮挡、镜头调整与镜头震动必须在 §9 说明；震动反馈必须写明触发、强度和持续时间，并提供关闭设置且不改变判定。

### VFX 时机合同
每个特效必须写清 `trigger event`、预备/前摇、active window、持续时间、结束条件、被打断/取消条件，以及和相机震动、音效、UI 的同步关系；命中特效、失败特效、胜利特效不能只写“有粒子”。
